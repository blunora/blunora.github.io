Information Hermes handles

Depending on the features you use, Hermes may handle:

  • Photos and artwork: images you select or import into Photo Vault, plus generated previews, mockups, and print files.
  • Creator content: slideshow text, captions, hashtags, Pin preparation fields, draft associations, and selected preferences.
  • Shop information: Etsy listing metadata and, when you request relevant Home, Orders, or Analytics views, information returned by Etsy through the configured Hermes backend.
  • Connection data: an authenticated session credential supplied to the app for requests to the configured Hermes backend. In the inspected iOS code, this credential is passed to the native Library session in memory for authenticated requests.
  • Operational diagnostics: the app and backend can record request outcomes, errors, and operational events. The inspected iOS target contains no advertising or third-party analytics SDK; this source review cannot rule out infrastructure-level logging by the live host or network providers.

Hermes does not need access to your entire Photos library to import an image: you select images through Apple's system picker. Saving exports to Photos uses the system's add-only permission.

How information is used

Hermes uses selected images and the content you enter to create previews, mockups, slideshow exports, and saved drafts. Local editing and rendering happen on your iPhone where the feature supports it. When you use connected features, the app sends the necessary request and content to the Hermes service.

The inspected backend stores app state, configuration, generated files, and service credentials in files under its configured data root; some Hermes orchestration records are JSON files. The deployment template mounts that root as persistent storage. The code does not define a universal retention schedule. Etsy requests are made by the backend using its Etsy integration, and Etsy handles submitted information under its own terms and privacy notice.

The app's Analytics views are for Etsy shop information returned by the connected service. They are not a claim that Hermes tracks your behavior for advertising.

Where information is stored

Photo Vault images, creator drafts, preferences, and related local records are stored in Hermes app storage on the device. The original app also uses its configured iOS App Group for data shared with its extension. Removing an item in Hermes affects the local record and files covered by that action; it does not necessarily remove a corresponding Etsy listing or backend copy.

The reviewed cloud deployment template stores service data on a persistent host volume mounted into the Hermes service. The repository does not identify the live hosting provider or the physical region used for the deployed volume. The source also does not specify a fixed retention period, backup lifetime, or automatic deletion schedule for all backend records and logs. These details depend on the operator's active deployment.

Etsy authorization tokens are read from backend-side credential files for Etsy API requests. The app uses a separate bearer credential to authenticate with Hermes; the iOS code passes that credential to native request code in memory. This review does not establish that Etsy credentials are stored in the iOS Keychain or encrypted at rest on the backend.

Third-party services and sharing

Hermes works with services you choose to connect or open, including Etsy. Their handling of information is governed by their own privacy terms. Hermes does not control those services.

  • Etsy: shop and listing information may be requested through the connected backend. Listing content and files are sent to Etsy when you use an Etsy workflow. Hermes source supports preparing Etsy drafts; publication or other Etsy actions depend on the specific feature and your confirmation.
  • Apple Photos: selected images can be imported from Photos, and exports can be saved to Photos if you grant permission.
  • System sharing: when you choose a sharing destination, iOS passes the selected item to that destination. For example, Pinterest export currently shares the selected image through the iOS share interface.
  • ChatGPT: if you choose ChatGPT in the share interface, the selected image and prepared prompt are handed to that app. Hermes does not make an OpenAI API request for this handoff.

Pinterest integration

The original Hermes iOS app does not sign in to Pinterest, read Pinterest boards, or publish Pins through the Pinterest API. Its current export sends the selected image through Apple's system share interface. Pinterest's own app or share extension controls which fields it accepts; Hermes does not guarantee that Pin title, description, hashtags, or destination URL will be filled automatically.

The source repository includes a separate Pinterest API agent and command-line authorization flow that can list boards or create Pins when supplied with an authorized token and app credentials. Those credentials are not present in the checked-in deployment template, and the cloud mobile API does not expose a Pinterest publishing route. I could not inspect the live server's persistent credential volume, so use of this separate provider by another operator process cannot be ruled out. It is not part of the iOS sharing workflow reviewed here.

Security

The reviewed cloud configuration places the API behind Caddy HTTPS and configures response headers including HSTS and content-type protection. Authenticated app API routes require a bearer token; pairing tokens are stored in backend-side files. The cloud process uses restrictive default file-creation permissions, but source inspection cannot verify the permissions of existing files, host security, encryption at rest, backup protection, or access by the live hosting provider.

Backend logs may contain operational events, request outcomes, identifiers, or error details. The source does not establish the live log destination or retention period. Keep your device secure and do not send passwords or access tokens in support requests.

Your choices and account disconnection

You choose which photos to import, what content to create, and whether to use system sharing or connected Etsy features. A paired mobile device can be revoked through Hermes' device-management controls. Etsy authorization is managed by the operator from backend-side credentials and can also be revoked with Etsy; local app removal does not itself revoke it. Pinterest authorization is not used by the reviewed iOS sharing flow.

Signing out of or removing Hermes from your iPhone does not necessarily remove backend records or information already held by Etsy, Apple, Pinterest, or another service.

Data deletion requests

Hermes provides feature-specific controls to remove some local posters, drafts, and files. The reviewed source does not provide a single account-wide deletion action that removes every device, backend, backup, and third-party copy. Deleting local content may not delete Etsy listings, backend files, logs, or third-party records.

To ask the operator about access to or deletion of information held by Hermes, use the privacy contact below. The operator will need to confirm identity and determine what information can be removed, including any copies subject to the deployment's backup and retention configuration. Do not include passwords or access tokens in a request.
